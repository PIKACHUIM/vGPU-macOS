独立用户态 GPU surface bridge 实测结果
日期：2026-11-16

交付边界
这是本模块自有 C API，经 IOServiceOpen(vgpuAccelerator, 0x56475055) 使用现有驱动 selector 3 clear 与 selector 1 readRow；不是系统 OpenGL，不导出任何 Apple GLD ABI，也不接入 GLEngine。
只有内核现有的一个 256x256 B8G8R8X8_UNORM 目标。多个 surface 句柄只是不同连接，互相覆盖同一目标，不是多资源。open 拒绝其他尺寸及 RGBA8 backing。读取输出仅 RGBA8，X 字节不代表 alpha，输出 alpha 恒为 255。clear 的 alpha 虽传给 GPU，但此 backing 不存储 alpha。
没有改驱动、安装、重启或 git 操作。宿主新增文件仅在指定目录和指定 probe 路径；客体仅使用 /var/tmp/vgpu-gld-surface-20261116 保存测试源码及可执行文件。

接口和地址规则
vgpu_surface_open/retain/release/close/clear/read，声明与约束见 vgpu_surface.h。
read 每次显式接收 rect、output_format、pack 和 destination capacity。
stride = stride_bytes 非零 ? stride_bytes : align_up((row_length 非零 ? row_length : width)*4,alignment)。
offset = skip_rows*stride + skip_pixels*4；第 j 行位于 offset+j*stride。
alignment 仅接受 1/2/4/8。显式 stride 覆盖 row_length，可不对齐。允许重叠行，按递增行号复制，与公式一致。
矩形必须非空且完全在 256x256 内；不裁剪、不重复加裁剪偏移、不翻转行。零面积返回 BadArgument（未提供隐式成功空操作）。
所有乘加、align_up、最终 extent/capacity/目标地址上界经检查；先完成全部临时缓冲读取和转换，再读一次同 generation 的行作为最终校验，然后复制有效行，保留 padding。
本连接 mutex 串行化 IO 与 close；分配、参数检查、最终目标复制在锁外。其他连接仍能提交，读取通过 generation 拒绝旧帧，不把某次 clear 的颜色当作读回结果。
成功快照的时间点为最终 selector 1 校验；校验之后其他连接可以开始新提交，API 不承诺到函数返回或任意未来时间仍是当前 generation。纯用户态接口无法锁住其他进程的整个提交期。
每个并发调用者须保有引用，最后 release 关闭连接并销毁 mutex；close 幂等且后续操作返回 NotOpen。调用者须保证输入/输出内存真实有效且调用期间不并发修改，不能把虚报 capacity 当作可写内存证明。禁止用 pthread cancellation 中断同步 API。

fault_probe.c 仅在专门测试构建中以 -DIOConnectCallMethod=surface_test_call 替换调用名，wrapper 通过 dlsym 调用真实 IOKit；产品构建没有注入入口。
在真实 clear 成功后注入 output count=2/4、width=255、height=257、generation=0，产品拒绝且 generation 输出不变。
在已成功读3行后注入行长度1023/1025或 IO error，返回 0xe00002ca，全部262144目标字节与guards仍为canary。
mode9 在第4行真实读完后通过另一连接执行真实 selector3 clear，随后同generation读失败，返回0xe00002d8；目标全部不变。
mode10 在第256行真实读完后通过另一连接执行真实 clear，最终附加行校验检测stale并返回0xe00002d8；目标全部不变。
上述两项不是伪造 stale 返回：wrapper 真实改变 GPU generation，下一次真实 selector1 返回 NotReady。
fault probe failures=0，ASan+UBSan 无诊断。
